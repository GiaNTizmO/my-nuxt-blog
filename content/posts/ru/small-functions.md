## Абстракция обещает экономию

Общий помощник появляется естественно: несколько похожих фрагментов хочется объединить. Но сходство строк ещё не означает сходства смысла.

Две операции могут выглядеть одинаково сегодня и изменяться по совершенно разным причинам завтра. Если связать их слишком рано, каждое изменение потребует новых параметров и условий.

## Хороший интерфейс ограничивает выбор

Удобный интерфейс делает типичный сценарий простым, а неправильное состояние — заметным. Он не обязан поддерживать все мыслимые варианты с первого дня.

```javascript
function formatArticleDate(date, locale = 'ru-RU') {
  return new Intl.DateTimeFormat(locale, {
    day: 'numeric',
    month: 'long',
    year: 'numeric',
  }).format(date);
}
```

Эта функция решает одну понятную задачу. Ей пока не нужна система плагинов, реестр форматов или собственный язык конфигурации.

## Проверка объяснением

Попробуйте описать новую абстракцию коллеге без показа реализации. Если объяснение начинается с длинного списка исключений, интерфейс, вероятно, ещё не устоялся.

Это не означает, что сложные системы всегда плохи. Иногда сложность соответствует задаче. Вопрос в том, какую часть этой сложности действительно нужно показывать пользователю вашего кода.

## Оставить место для наблюдений

Небольшое дублирование может быть временной платой за понимание. Когда появятся реальные сценарии изменения, станет легче провести границу и выбрать общее имя.

Главное — возвращаться к этому решению осознанно, а не считать любой повтор окончательным устройством проекта.
